# Peltor Audio

Plays phone media (Spotify etc.) through a calls-only Bluetooth headset
(like an old Peltor WS Alert that shows up as "PeltorWS3") by keeping the
Bluetooth call channel open. No ads, no time limits.

Build: push to GitHub; the "Build APK" action builds it and attaches
PeltorAudio.apk to the "latest" release.
